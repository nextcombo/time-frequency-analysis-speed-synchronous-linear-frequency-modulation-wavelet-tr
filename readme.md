# Time-Frequency Analysis: Speed Synchronous Linear Frequency Modulation Wavelet Transform [with MATLAB Code]

Introduction: Fault analysis is an effective method for monitoring and diagnosing rotating machinery [1], [2]. A significant portion of the work in rotating machinery operates under varying speeds and loads; therefore, vibration signals collected from such machines are non-stationary, with amplitude and frequency components changing over time. Time-frequency methods are an effective tool for revealing time-varying characteristics, making them widely applied in the analysis of non-stationary vibration signals.
Linear transformations are perhaps the most widely used family of time-frequency analysis. They can be seen as a process that decomposes the signal into weighted basis functions, representing the weights on the time-frequency plane to obtain the time-frequency representation. One disadvantage of current linear transformations is their trailing effect, which arises from the mismatch between the base frequency of the substrate and the frequency component of the signal. For example, the fundamental frequency of Short-Time Fourier Transform (STFT) [3] and Continuous Wavelet Transform (CWT) [4] is fixed, which is not suitable for analyzing non-stationary signals. Linear Frequency Modulation Wavelet Transform (LCT) [5], Polynomial Frequency Modulation Wavelet Transform (PCT) [6], [7] and other variants [8], [9] use bases with frequency-invariant modulation ratios, thus they can only remove tails from signals whose modulation ratio equals the preset modulation ratio. However, since the linear frequency modulation ratios of vibration signal components differ, LCT cannot provide untailed TFR for such vibration signals collected from rotating machinery. According to Heisenberg's uncertainty principle, the time-frequency resolution of linear transformations is limited [10]. An increase in resolution in one dimension (frequency or time) will result in a reduction in resolution in the other dimension. Since most linear transformations use windows with constant time-invariant window lengths, the resulting TFR has time-invariant resolution in both dimensions. However, due to the characteristic time-variability of non-stationary signals, existing linear transformations may lack the ability to provide appropriate time-frequency resolution.
TFR data remapping methods are a family of post-processing techniques based on linear transformations, such as the reassignment method (RM) [12], synchronous compression transform (SST) [13], and synchronous extraction method (SET) [14]. These methods first use traditional linear transformations (STFT or CWT) to obtain TFR, then generate the final TFR by remapping the original TFR data to new coordinates based on the phase of the original TFR. In this way, the TFR data remapping methods sharpen the ridgelines of the linear transformations used. However, this method cannot improve the time-frequency resolution [15].
The bilinear distribution is another class of time-frequency methods [16] with good time-frequency resolution. However, for multicomponent signals, the bilinear distribution exhibits crosstalk interference. Cohen's class bilinear distribution uses kernels in the fuzzy domain to suppress crosstalk interference, such as ZAM [17], [18]. However, this is at the cost of solving problems, and it requires prior knowledge of the crossterms and car terms' positions. Moreover, the results are often influenced by human intervention because such kernel functions typically contain parameters that need to be specified by the user.
In recent years, optimization methods for linear transformation parameters have attracted more attention. The adaptive slope transform is used to determine the window length [19]. However, since it uses a fixed frequency kernel, it is not suitable for analyzing signals with frequency changes. Generalized parameter time-frequency transform (GPTFT) selects the kernel and its parameters through iterative fitting of TFR ridge lines [20]. However, alternating kernels belong to the linear frequency modulation wavelet transform family, so this method cannot eliminate the trailing effect of non-stationary vibration signals. General linear frequency modulation wavelet transform (GLCT) is a TFR fusion method to alleviate the trailing effect [21]. It first generates multiple sub-TFRs using LCT with a series of linear frequency modulation rates, and then fuses these sub-TFRs into one TFR. However, this method uses a fixed window length, resulting in a fixed resolution.
The conclusion of this paper proposes a new linear transformation, VSLCT, for analyzing non-stationary vibration signals collected by rotating machinery. This method can also be applied to the analysis of normal single-component frequency modulated signals. The definition of linear transformation is first extended to provide a theoretical basis for VSLCT. The new definition allows for non-orthogonal bases and time-varying window lengths. This new definition may also prompt the design of other linear transformations for new applications. Compared with existing linear transformations, the main improvements and advantages of this method are summarized as follows. It is free from contamination because it uses a set of bases that match the frequencies of signal components. It generates appropriate time-frequency resolution because the window length can be dynamically calculated based on the signal. VSLCT does not require any user-provided parameters, thus eliminating the need for easy-to-make human intervention. Testing was conducted using synthetic and experimental signals. The test results indicate that the algorithm has strong robustness against noise and high computational efficiency. Although VSLCT has the advantages shown previously, it also has some limitations. Limited by the linear transformation framework, VSLCT has relatively lower resolution compared to bilinear distribution, and the ridge lines of VSLCT results are not as clear as those of TFR data mapping methods.
